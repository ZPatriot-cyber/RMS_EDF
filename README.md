## 🩺 О проекте

Узел медицинского монитора одновременно снимает кардиосигнал, измеряет пульс
и передаёт данные по сети на центральный пост — и всё это на одном
процессоре. У каждой задачи свой период и свой дедлайн. Вопрос, который
решает эта программа: **успеет ли процессор выполнить все три задачи
вовремя, и какой ценой?**

Программа прогоняет набор задач через два классических алгоритма
планирования — **RMS** (приоритеты фиксированы, статически, по периоду) и
**EDF** (приоритеты динамические, по ближайшему дедлайну) — и честно
показывает, где быстрый приближённый тест может ошибиться, а где нужен
точный расчёт.

**Вариант:** узел медицинского монитора — ЭКГ, пульс, передача по сети.

---

## ⚙️ Что умеет программа

| Возможность | Описание |
|---|---|
| 📊 Коэффициент загрузки | `U = Σ(Cᵢ / Tᵢ)` |
| 📐 Тест RMS (быстрый) | сравнение `U` с границей Лю-Лейланда `n·(2^(1/n) − 1)` |
| 🎯 Анализ времени отклика | точный тест планируемости по рекуррентной формуле RTA |
| ✅ Тест EDF | необходимое и достаточное условие `U ≤ 1` |
| 📅 Диаграмма Ганта | симуляция вытесняющего выполнения на интервале гиперпериода |
| 🎨 Цветной вывод | раскраска занятых тактов в консоли по ANSI-кодам |
| 📂 Гибкий ввод | задачи читаются из `.json` или `.csv` — формат определяется сам |

Входные данные — обычный файл, а не «магические числа» в коде. Хотите другой
вариант? Меняете `tasks.json`, программа — нет.

---

## 🧠 Как это устроено внутри

1. **Загрузка.** `TaskLoader` читает список задач — JSON или CSV, по
   расширению файла.
2. **RMS по утилизации.** Коэффициент загрузки сравнивается с границей
   Лю-Лейланда — быстрый, но приближённый тест.
3. **Анализ времени отклика.** Для каждой задачи по приоритету (от короткого
   периода к длинному) считается точное время отклика `R` и сверяется с
   дедлайном `D`.
4. **EDF.** Проверяется условие `U ≤ 1` — простое и точное для задач с
   неявными дедлайнами.
5. **Диаграмма Ганта.** Симулируется вытесняющее выполнение с шагом 0,5
   такта на интервале гиперпериода, соседние кванты одной задачи сливаются в
   отрезки.
6. **Вывод.** Таблица, оба теста и диаграмма печатаются в консоль.

Код разделён на независимые классы: `Scheduler` — только формулы,
`TaskLoader` — только чтение, `GanttRenderer` — только вывод. Поменять
формат входных данных можно, не трогая расчёты.

## 🚀 Запуск

### Через Visual Studio

1. Откройте `.sln` в Visual Studio.
2. Проверьте, что `data/tasks.json` настроен на копирование в выходной
   каталог (**Свойства файла → Копировать в выходной каталог → Копировать,
   если новее**).
3. Нажмите **F5**.

### Через командную строку

```bash
dotnet run --project RMS_EDF -- data/tasks.json
```

> 💡 Цветная диаграмма использует ANSI-коды — для корректного отображения
> запускайте из Windows Terminal, встроенного терминала VS Code или
> PowerShell 7+. Старый `cmd.exe` без включённого виртуального терминала
> покажет вместо цвета «сырые» управляющие символы.
